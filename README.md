🛒 **GroceryTracker – iOS Grocery Management Application** 📱

Excited to share one of my iOS development projects, **GroceryTracker**, developed using **Swift** and **Xcode** to help users efficiently manage their grocery shopping and household inventory.

🚀 **Key Features**
✅ Create and manage grocery lists
✅ Track purchased and pending items
✅ Organize groceries by categories
✅ Monitor household inventory efficiently
✅ User-friendly and intuitive interface
✅ Secure data management and storage

🛠️ **Technologies Used**
🔹 Swift
🔹 Xcode
🔹 iOS Development
🔹 Object-Oriented Programming (OOP)
🔹 UI/UX Design
🔹 Data Management

💡 **Project Impact**
This project enhanced my understanding of mobile application development, software design principles, user experience optimization, and data management. It also strengthened my problem-solving abilities by applying theoretical concepts to a practical, real-world solution.

Through GroceryTracker, I gained valuable hands-on experience in designing and developing scalable iOS applications while focusing on usability, efficiency, and functionality.
